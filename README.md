# Muhammad Daniyal — Portfolio Website

A modern, high-performance personal portfolio built with **Next.js (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**.

Designed specifically to showcase artificial intelligence, computer vision, deep learning research, and full-stack engineering work.

---

## ⚡ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library:** [React 19](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Motion](https://motion.dev/) & [OGL](https://github.com/oframe/ogl) (WebGL)
- **Icons:** [Hugeicons](https://hugeicons.com/) & [Simple Icons](https://simpleicons.org/)

---

## ✨ Key Features

- **Hero & Interactive Shaders:** Engaging intro gate and custom interactive WebGL/Motion background elements.
- **Projects Showcase:** Categorized, filterable showcase of AI, Computer Vision, and full-stack projects with live demo and source code links.
- **Technical Skills Matrix:** Interactive domain-based breakdown of tools, frameworks, and proficiencies.
- **Engineering Principles:** Clean, structured insights into development philosophy, architecture, and code quality.
- **Experience Timeline:** Detailed milestones and educational background.
- **Contact & Direct Email:** Pre-formatted mailto generation and direct social connectivity.
- **Responsive & Accessible:** Dark-mode optimized, keyboard navigable, and responsive across all viewports.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18.18.0 or higher recommended)
- `npm`, `yarn`, `pnpm`, or `bun`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aurabydaniyal/muhammad-daniyal-portfolio.git
   cd muhammad-daniyal-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

---

## 🛠️ Available Scripts

- `npm run dev` — Starts the Next.js development server with Turbopack.
- `npm run build` — Creates an optimized production build.
- `npm run start` — Starts the production server after building.
- `npm run lint` — Runs ESLint to check for code issues.

## 🌐 Deployment

The easiest way to deploy this Next.js app is using the [Vercel Platform](https://vercel.com/):

1. Push this repository to your GitHub account.
2. Import the project into [Vercel](https://vercel.com/new).
3. Vercel will automatically detect Next.js and configure the build settings (`npm run build`).
4. Click **Deploy**.
